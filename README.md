# NILAVU: Project V

A responsive, cinematic landing page for an original Kerala-set survival horror game concept.

## Concept

The V-Virus emerged from V-Genesis, a healing programme developed by the covert VAYU research organisation in Kerala's Western Ghats. A secret military experiment transformed the programme into an outbreak. Forest tracker Arjun Dev enters the sealed valley after a distress call from his sister Meera, a junior technician at VAYU.

## Features

- Cinematic hero section and atmospheric visual system
- Responsive layouts for mobile, tablet, and desktop
- Scroll-triggered reveal animations and subtle hero parallax
- Mobile navigation with accessible state
- Interactive threat dossier tabs
- Reduced-motion support
- Story, world locations, protagonist profile, bestiary, and recovered transmission sections
- No framework, build step, API key, or backend required

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This is a static website. It can be deployed with GitHub Pages, Vercel, Netlify, or any static host. For GitHub Pages, select the repository's root directory as the deployment source.

## Assets and content notes

The current visual mood boards use remote Unsplash image URLs and Google Fonts. An internet connection is required for those assets. Replace these URLs with licensed or original game artwork before commercial release.

All story copy and creature classifications on this page are concept material for the NILAVU game project, not claims about a released game.
